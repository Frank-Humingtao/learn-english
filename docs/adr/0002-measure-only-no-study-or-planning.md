# 只做词汇测量：背词、选词和内容推荐都交给系统外的工具

本系统只负责一件事：定期、准确地测出 Learner 的词汇水平，并公开发布，供 Recommendation Agent 读取。

学英语用三个工具，各管一段：

- **墨墨背单词**：每天背词。它有自己的词库、记忆曲线和每日计划。
- **Recommendation Agent**（外部的 Grok bot）：每天读取本系统发布的数据，也直接读取墨墨的学习数据，自己把两边对上，再推荐阅读和视频。
- **本系统**：提供更大范围的词汇数据。墨墨只覆盖计划里的词，本系统覆盖整个词库：Learner 认识多少词、认识哪些词。

因此删掉以下部分：卡片学习（FSRS 调度、Study Session Composer、Leech、个人 FSRS 参数）、Word Planning 与 Study Plan（`word-plan` skill、计划同步），以及 App 的"学习"标签。Observation 只来自 Vocabulary Test。

之所以这样设计：

- **墨墨的背词体验更好**：墨墨打磨多年，它的卡片、记忆曲线和每日计划都比我们自己做的好。在背词上自研没有意义，地图里也早就写明"卡片本身不在这里创新"。
- **系统里唯一不可替代的是测量**：调研过的现成测试（BRAVE、VST、扇贝、墨墨等，见 research 07 与 2026-11-13 的讨论）都只给一个总数，没有一个能导出每个词的认识概率。而推荐质量取决于逐词数据的准确程度。
- **数据只合并一次**：墨墨的 API 由 Recommendation Agent 自己读，两边数据有矛盾时由它来判断。本系统不读墨墨的数据（不作为证据，也不作为验证集），以免多一份公测接口的依赖，也免得要维护两套作答模型。

## Considered Options

- **墨墨接管背词，本系统选词后推送进墨墨**：被否决。墨墨自己的规划已经够用，选词规划的价值不足以抵消它的复杂度。
- **把墨墨的每日反馈并入 Learner Profile**：被否决。理由是不增加复杂度，而且 Recommendation Agent 已经能直接读墨墨。
- **改用外部测试（如 BRAVE）的总数，不再自己出题**：被否决。外部测试只给一个总数，拿它算不出文章的 Coverage。

## Consequences

- 票 07（卡片学习）、08（选词规划）、10（个人 FSRS 参数）的代码删除，git 历史里还能找回。地图中关于卡片、Leech、Study Plan 的决定作废。
- Progress Report 和公开档案不再含 `focus_targets`。
- 下一步的重点是测量本身：先做离线评测，再按评测结果重写模型，然后改进测试流程和界面（见 research 07）。
