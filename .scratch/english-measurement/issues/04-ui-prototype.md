# 04: 极简 UI 原型

Status: ready-for-human

**What to build:** 用一个能点的 HTML 原型（`prototype` skill）展示新界面，由 Learner 在手机上看过、定下风格后再改 App。

- 三个标签：测试、进度、设置。全局不放说明性小字。
- 测试主屏：大数字（当前词汇量）、一行区间、"开始测试"按钮（自动判断做基线还是短测、是否续测），以及最新 Progress Report 的链接。
- 答题屏：
  - 一个单词和"认识 / 不认识"，可以左右滑动，也可以点按钮；
  - 翻卡动画、触感和音效；
  - 词汇量随作答实时跳动；
  - 假词和释义题当场判对错（✓ / ✗，答错时给出正确意思）；
  - 左上角 ✕；进度条要有节奏感。
- 结果页：新的词汇量和较上次的变化，外加"完成"按钮；作答异常时多一行提示。
- 进度页：曲线、三类词、频段掌握率等图表，去掉说明小字。
- 设置页：令牌、同步状态、重做基线测试。同步状态只在出错时显示在顶部。
- 原型做好后需要 Learner 评价（ready-for-human），反馈记在 Comments 里。
