# 01: 离线评测

Status: resolved

**What to build:** 一个能重复运行的离线评测：给定一份 Observation 和一个模型版本，输出一组准确度指标，并和"只用词频"的对照模型并排比较。之后每次改模型都先跑它。

- 数据来源：
  - Learner 的真实 Observation（从本机 `english-data` 读取，不入本仓库）；
  - 已知真实知识状态的模拟学习者，包括诚实作答和会虚报两种。
- 指标（定义和初始阈值见 [调研 07 §E](../../english-learning-system/research/07-accurate-vocab-measurement.md)）：
  - 留出 log loss、Brier、AUC：每场测试前用历史数据预测本场真词，事后对照；
  - 校准误差 ECE（10 个分箱）；
  - 总数 95% 区间半宽；
  - 折半一致性：同一场奇偶题分别估计；
  - 重测一致性；
  - 模拟学习者的真实值是否落在区间内。
- 形式：`profile-engine` 新增一个 `eval` 子命令，或者另做一个同包的可执行文件，输出一份 JSON 和一张人能读的表格。
- 对现有模型跑一次，把结果作为基线记录在本票的 Comments 里。

## Comments

### 2026-11-13 实现与基线结果（agent）

**实现**：`EnglishCore/Sources/ProfileEval/`（新库）+ `profile-engine eval` 子命令。

```
swift run --package-path EnglishCore profile-engine eval \
  --lexicon tools/lexicon-build/out --observations ~/Documents/english-data/observations --out /tmp/eval
```

- 模型接缝：`VocabularyModel` 协议，`fit(observations:lexicon:) -> ModelFit`。`ModelFit` 给出逐词 P_know（发布值）、lemma/词族总数及 95% 区间，以及 `respond(entry, kind)`——对 Yes/No 题预测 P(yes)、对核验题预测 P(答对)。作答层（猜测、漏答）只能放在 `respond` 里，不能混进 P_know。票 02 的新模型实现这个协议，再在 CLI 的 `evalModels` 里登记一个名字即可并排比较（`--models current,frequency,<新名字>`）。
- 已接入两个模型：`current`（现有 ProfileEngine，未改动；Yes/No 的 P(yes) = g + (1−g−s)·P，与它自己的似然一致）；`frequency`（对照：P = σ(a − b·ln(rank/1000))，用所有真词作答拟合，无逐词偏差、无作答层、无衰减）。
- 指标定义：
  - **留出(按场次)**：按开始时间排序，每场用该场开始之前的全部 Observation 拟合，预测本场真词作答（Yes/No 和核验）；没有任何历史证据的场次（即第一场）跳过。
  - **交叉验证(按词)**：真实数据目前只有一场之后还有一场短测（留出 n=66），所以另加 10 折按词交叉验证（词按 FNV 哈希分折，同一个词的所有作答同折；伪词始终留在训练集）。这是补充指标，不按时间，结果会比真正的留出偏乐观。
  - log loss（自然对数，截断 1e−6）、Brier、AUC（并列取平均秩）、ECE（10 个等宽分箱）。
  - **区间半宽**：用全部 Observation 拟合后的 95% 区间半宽 / 估计值。
  - **折半**：每场按"词首次出现的顺序"奇偶交替分两半（核验跟着它的词走，伪词也交替），两半各自单独拟合；|A−B| ≤ 1.96·√(seA²+seB²) 记为一致。每半至少 20 道可评分题。
  - **重测**：相邻且相隔 ≤7 天的两场各自单独拟合，同样的一致判据；另给出同词跨场 Yes/No 一致率（与模型无关）。
  - **模拟学习者**：真知识 P = σ(θ − 1.6·ln(rank/1000) + ε_w)，ε_w ~ N(0, 1)；θ ∈ {0.5, 2.0, 3.5} × {诚实, 虚报} × 每组 2 人 = 12 人。每人一场 450 题基线 + 一场 250 题短测（25 个 ln rank 分层等量抽样、伪词 15%、答 yes 后 10% 追问核验，不知道的词核验猜对率 0.3）。诚实：不认识答 yes 3%、伪词 yes 3%；虚报：不认识答 yes 25%、伪词 yes 8%。报告真值是否落在区间内、相对误差和偏差，以及逐词 P_know 对真知识状态的 log loss / ECE。种子固定，结果可重复（`--sim-seed`、`--sim-learners` 可调）。

**看到的问题**：

1. **离线评测下，现有模型并不比"只用词频"好。** 留出 log loss 0.608 vs 0.610、Brier 相同，AUC 反而更低（0.585 vs 0.648）；按词交叉验证几乎打平（0.630 vs 0.629，AUC 0.553 vs 0.556）。逐词偏差 u_w 和猜测层没有带来可测到的预测收益。两者 AUC 都远低于 .80 的目标，ECE 也超过 .05。
2. **AUC 低的直接原因是选题。** 570 道真词 Yes/No 里有 494 道落在 lemma 排名 2k–8k（442 道在 2k–4k），排名 8k 以后一道都没有。题目集中在 P≈0.5 附近，按频率本来就分不开；而总量的大头（8k–43k lemma）完全是外推。这正是调研 07 §0 的诊断，票 03 的分层抽样必须覆盖长尾。
3. **区间半宽远超目标**：词族 ±48%（现有）/ ±41%（词频），目标是基线后 ≤ ±20%。
4. **虚报学习者两种模型都测不准。** 诚实学习者的词族真值 100% 落在区间内；虚报学习者词族偏高 +74%（现有）/ +99%（词频），真值几乎都在区间外。现有模型的伪词猜测率修正只挡住了一小部分虚报。票 02 的作答层（漏答 s、误报 f）和核验题似然要专门解决这一点。
5. **lemma 区间在模拟中覆盖不足**：诚实学习者的 lemma 覆盖率只有 83%（现有）/ 17%（词频），区间偏窄。词族和 lemma 的口径差异也需要在票 02 里核对。
6. **折半、重测都"一致"，但没有区分力**：两半和短测各自的区间都很宽（短测只有 66 题），差值落在合并区间内几乎必然。等区间收窄后这两项才有意义。同词跨场重测目前只有 2 对。
7. 留出只有 n=66（第二场短测），核验题只有 36 道，这些数字本身噪声很大；要等更多场次再看趋势。
