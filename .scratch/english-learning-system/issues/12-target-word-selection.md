# Target 词的选取与排序

Type: grilling
Status: resolved
Assignee: humingtao
Blocked by: 07
Part of: ../map.md

## Question

Target 里可能有一两千个词。每次学习时，由 AI 决定引入哪些新词、按什么顺序复习。这和推荐阅读与视频是同一套"按水平定制"的思路，只是落在 App 内的卡片上。

具体要回答：
- 每天引入多少新词，挑哪些。依据可以是词频、"似懂非懂"程度、即将推荐的文章或视频里会出现的词。
- AI 和 FSRS 如何分工：FSRS 管"什么时候复习"，AI 管"学什么、先学什么"。
- 顽固词（忘了 8 次以上）怎么处理。
- 由谁来跑这套规划：设备端、Actions，还是外部 agent。规划结果存在哪里。

### 来自「进度汇报 issue 的格式」的补充

- Progress Report 的 `focus_targets` 最多放 50 个词，原样照抄 `recent.json`。这张票的规划结果要能产出这份按优先级排好的列表。
- 报告另有 `newly_mastered`（自上一份以来新掌握的词，最多 30 个），由 Word Band 的变化直接算出，不归这张票管。
- 系统不再接收推荐结果，所以「即将推荐的文章或视频里会出现的词」不能作为选词依据。

### 来自「App 的屏幕与流程原型」的补充

- App 用底部标签栏，「学习」标签显示今天到期的复习数和新卡数。这张票要定出每天新卡的数量，以及新卡和复习如何排在同一次学习里（先复习再学新卡，还是两者穿插）。
- 卡片评分是 4 档（FSRS 的 Again / Hard / Good / Easy），可以作为判断「似懂非懂」的依据之一。

## Answer

学习者的选择：
- **选词交给「选词规划」，不用固定算法，也不接 API**：新写一个 Claude skill `word-plan`（与学习者已有的「备课」skill 无关），在 Claude 桌面 App 里运行。它读私有仓库 `english-data` 的测试与复习记录、学习档案和设置，写出一份 **Study Plan（学习计划）**：按顺序排好的新词，每个词附一句**选词说明**（为什么现在学、易混词、记忆提示），外加最多 50 个重点词。「AI 按水平定制」落在这里：由 Claude 结合测试结果做定制分析，而不是套固定公式。
- **触发**：本机定时任务每天跑一次，也可以随时手动运行。
- **每日新词数**：在 App「设置」里填上限，随同步写进仓库；选词规划在上限内灵活决定每天实际学几个（例如复习积压多就少排）。
- **一次学习的顺序**：先复习，再学新卡；中间有分隔页「复习完成，开始 N 个新词？」，可以停在这里。
- **新卡第一次就评「太简单」**：视为已认识，卡片暂停，这次作答作为一条强「认识」证据进入 P 的计算；当天从计划里补一张新卡。
- **顽固词（Leech，忘了 8 次以上）**：暂停卡片，在「进度」页列出「顽固词」清单；学习者可以手动点「重新学」（卡片重置），否则 30 天后自动重新引入一次。Word Band 仍只由 P 决定，**不再**按「调研：间隔重复算法与 Anki 卡组格式」的设想降为 Distant。
- **选词说明**：显示在卡片背面中文释义下方；没有时不显示。
- **`focus_targets`**：由选词规划直接写出排好序的重点词（≤50），Actions 生成 `recent.json` 时原样照抄，Progress Report 再照抄 `recent.json`。
- **手动加词**：App 提供「加词」入口，记一条「想学」记录；下次选词规划必须把它排进计划。
- **计划用完时**：不兜底补词。只做复习，「学习」标签显示「学习计划已用完，去跑一次选词规划」。学习者自己保证定时任务在跑，个人项目可以容忍这个小缺口。

实现细节（agent 决定）：
- **存放**：Study Plan 存在 `english-data/plan/YYYY-MM-DD.json`，每次运行新写一个文件，App 读日期最新的一份。字段：`generated_at`、`daily_new`（每天建议数）、`new_words`（有序数组，每项 `lemma` 与 `note`）、`focus_targets`（≤50）。每份至少排够 7 天的新词（`daily_new × 7`）。
- **写入方**：Study Plan 不是派生数据（大模型输出不可复现地重算），和 Observation 一样属于**输入**。因此「派生数据只由 Actions 写」不变，但 `english-data` 多了一个写入方：选词规划只追加 `plan/` 下的新文件，不碰其他路径，与 iPhone、Actions 都不冲突。运行前先 pull，写完提交并 push。
- **设置与加词**：每日上限和手动加词都作为 iPhone 写入的记录进 `observations/iphone/`（`source: setting` / `source: wish`），保持只追加。
- **4 档评分的用法**：FSRS 用全部 4 档；词汇量模型把「忘了」算作不认识，其余三档算作认识；完整评分历史（如「模糊」偏多）交给选词规划，作为判断「似懂非懂」的依据。
- **App 端取新卡**：当天新卡数 = min(`daily_new`, 设置上限)，按计划顺序跳过已有卡片、已 Mastered 或已评「太简单」的词。新卡和到期复习都由 FSRS 调度，选词规划只管"学什么、先学什么"。
- **顽固词重新引入**：卡片重置后按新卡处理，排在当天新卡最前面，计入当天新卡上限。
